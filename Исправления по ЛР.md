## 7. ЛР-2: Следующий через БД

**Замечание:** "следующий переделать через БД. Но ид могут быть с пропусками"

**Исправление:**

**Файл:** `repositories/gate_repo.py`

```python
async def next_published_id(db: AsyncSession, gate_id: int):
    # Ищем минимальный ID больше текущего среди опубликованных
    stmt = select(func.min(Gate.id)).where(
        Gate.id > gate_id,
        Gate.status == "published"
    )
    result = await db.execute(stmt)
    next_id = result.scalar_one_or_none()
    
    # Если следующий ID не найден, возвращаем первый опубликованный (циклический переход)
    if next_id is None:
        stmt = select(func.min(Gate.id)).where(Gate.status == "published")
        result = await db.execute(stmt)
        next_id = result.scalar_one_or_none()
    
    return next_id
```

**Скриншоты:**
- **Рис.9** — Скриншот кода `repositories/gate_repo.py` с функцией `next_published_id`. Видно SQL-запрос `SELECT MIN(id) WHERE id > {current_id}`.

async def get_draft_for_user(db: AsyncSession, user_id: int):
    """Получает последний гейт пользователя (черновик или любой другой)."""
    stmt = (
        select(Gate)
        .where(Gate.creator_id == user_id)
        .order_by(Gate.id.desc())
        .limit(1)
    )
    result = await db.execute(stmt)
    return result.scalar_one_or_none()
